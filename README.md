# Графік відключень → картинка в Telegram (GitHub Actions)

Кожні ~10 хвилин GitHub запускає `run.py`: той дивиться останній графік у каналі,
малює картинку і бот розсилає її підписникам. Безкоштовно, без сервера і без картки.

## Налаштування (один раз, ~10 хв)

1. **Бот.** У @BotFather: `/newbot` → скопіюй токен.
2. **Репозиторій.** На github.com → New repository → назва будь-яка →
   **Public** (для публічних репозиторіїв хвилини Actions безлімітні) → Create.
3. **Файли.** На сторінці репозиторію: *uploading an existing file* → перетягни
   **весь вміст** розпакованої папки (разом із папками `.github` і `fonts`) → Commit changes.
4. **Секрети.** Settings → Secrets and variables → Actions → *New repository secret*:

   | Name | Значення |
   |---|---|
   | `BOT_TOKEN` | токен бота |
   | `CHANNEL` | назва каналу, напр. `khoe_official` або `https://t.me/khoe_official` |
   | `STATE_KEY` | будь-який довгий пароль (вигадай; ним шифрується список підписників) |
   | `ALLOWED_IDS` | *необов'язково*: ID людей через кому, хто може підписатися |

5. **Запуск.** Вкладка **Actions** → якщо просить — увімкни workflows →
   «Графік відключень» → **Run workflow**. Через ~1 хв має бути зелена галочка.
6. Відкрий свого бота в Telegram → **Start**. Протягом ~10–15 хв прийде останній графік.
   Скинь посилання на бота іншим — хто натисне Start, теж отримуватиме.

## Команди в боті
- `/queue 3.1` — своя підчерга (в підписі будуть саме твої години)
- `/now` — останній графік
- `/stop` — відписатися

Бот відповідає не одразу, а при наступному запуску (до ~15 хв).

## Якщо канал ПРИВАТНИЙ
Публічний канал читається без входу (через сторінку t.me/s/канал).
Для приватного додатково:
1. На https://my.telegram.org → API development tools → візьми `api_id` і `api_hash`.
2. На своєму комп'ютері: `pip install telethon` → `python make_session.py` → введи номер і код.
3. Додай секрети `TG_API_ID`, `TG_API_HASH`, `TG_SESSION` (той довгий рядок).
   ⚠️ `TG_SESSION` — це доступ до твого акаунта, нікому його не показуй.

## Корисне
- Логи кожного запуску: вкладка Actions → клікни на запуск.
- GitHub вимикає розклад, якщо в репозиторії 60 днів немає змін. Бот сам комітить
  `state.bin` при кожному новому графіку, тож поки графіки виходять — усе працює.
  Якщо раптом вимкнувся: Actions → Enable workflow.
- Якщо змінити `STATE_KEY`, видали `state.bin` (підписникам доведеться натиснути Start знову).
